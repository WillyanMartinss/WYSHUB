Coloque aqui os instaladores offline que o assistente de instalação deve usar.

O assistente procura automaticamente os seguintes arquivos:
- vc_redist.x64.exe
- dotnet-runtime-8*.exe

Se você tiver os instaladores oficiais da Microsoft para o .NET 8 Runtime e para o Visual C++ Redistributable, basta copiá-los para esta pasta.

Exemplo de nomes de arquivo:
- dotnet-runtime-8.0.XX-win-x64.exe
- vc_redist.x64.exe
